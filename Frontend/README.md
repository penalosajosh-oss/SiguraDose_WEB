# SiguraDose – Smart Medication Management Web Application

SiguraDose is a web-based medication management application designed to support elderly patients and their caregivers in managing medication schedules and monitoring medicine inventory.

The website serves as the digital interface of the SiguraDose Smart Medication Dispenser. It allows caregivers to manage patient information, organize medication schedules, monitor medication availability, and review medication intake records.

## Key Features

- **Patient Management** – Register patients and manage their medication profiles.
- **Medication Management** – Add, update, and organize prescribed medications.
- **Medication Scheduling** – Set medication schedules and dosage information.
- **Inventory Monitoring** – Monitor the remaining quantity of medicines through load-cell-based inventory tracking.
- **Medication Intake Monitoring** – View and track medication intake records.
- **Caregiver Dashboard** – Provide caregivers with an overview of patient medication activities and inventory status.
- **IoT Integration** – Connect the web application to the smart medication dispenser for data monitoring and synchronization.

## Technology Stack

The SiguraDose web application uses the following technologies:

- **React.js** – Frontend development and user interface.
- **Vite** – Development server and build tool.
- **JavaScript** – Application functionality.
- **CSS** – Website styling and layout.
- **Axios** – Communication between the frontend and backend.
- **Node.js and Express.js** – Backend development and API management.
- **MySQL / SQLite** – Database management and storage.

## Project Purpose

The purpose of SiguraDose is to provide an accessible and organized platform for medication management. Through its web interface, caregivers can conveniently manage medication information, monitor inventory levels, and review medication activities, helping support medication adherence among elderly patients.
